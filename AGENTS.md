## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## Deployment

Sites deploy by **SSH/rsync to the Caddy server** (`192.168.0.62`), not Firebase Hosting or other platforms. Build Astro static output, rsync `dist/` to `/var/www/<hostname>/`, Caddy serves it. Requires home LAN or VPN. See `.cursor/rules/deployment.mdc` for host paths.
